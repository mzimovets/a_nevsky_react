# Расписание Богослужений Александро-Невского собора

## Форма для составления расписания богослужений

Форма предназначена для составления расписания богослужений в **Александро-Невском соборе**.

### Основные возможности:

- **Загрузка документов**: возможность загружать файлы в формате **DOCX**, на основе которых составляется расписание.
- **Редактирование текста**: возможность форматировать текст:
  - _Курсив_
  - **Жирное начертание**
  - Изменение шрифта, размера и цвета текста.
- **Экспорт расписания**: функция экспорта готового расписания в формате **PNG** высокого качества.

### Работа с данными:

Благодаря использованию базы данных, все введённые данные сохраняются на сервере, что позволяет:

- Продолжать работу над расписанием с разных устройств.
- Обеспечивать совместную работу над проектом, сохраняя весь процесс в одном месте.
